# 🗺️ 02 — Journey Map

Travel users don't think in verticals. They think in trips.

## 📄 Files

| File | Content |
|---|---|

## 💡 Key insight

A trip from HCMC to Da Nang might involve: flight, hotel, airport transfer, car rental. That's 4 verticals in one trip.

Growth opportunity lives in the gaps between those verticals, not inside each one separately.
