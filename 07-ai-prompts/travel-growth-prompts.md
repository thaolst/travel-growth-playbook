# 🤖 AI Prompt cho Travel Growth Marketing

Prompt được viết riêng cho travel vertical — không phải prompt marketing chung rồi adapt.

Mỗi prompt được design xung quanh quyết định thực tế mà travel marketer phải đưa ra: segment user như thế nào, design campaign ra sao, diagnose retention problem ở đâu, brief partner thế nào.

## Cách dùng

Mỗi prompt có cấu trúc fill-in. Thay bracket bằng context cụ thể của bạn. Input càng cụ thể, output càng hữu ích.

Prompt work trên Claude, ChatGPT, Gemini, hoặc bất kỳ AI assistant nào có capability tốt.

---

## 1. Segment user

### Phân loại user vào travel segment

```
Tôi có một travel user với hành vi sau:

Lịch sử booking:
- Số lần book: [X]
- Vertical đã dùng: [airline / bus / train / hotel — liệt kê tất cả]
- Loại điểm đến: [biển / núi / thành phố / về quê]
- Đi với: [một mình / cặp đôi / gia đình / nhóm bạn]
- Book trước bao lâu: [trung bình X ngày/tuần]
- Khoảng chi tiêu: [budget / mid-range / premium]

Phân loại user này vào một trong 4 segment:
- Connection Seeker (đi để kết nối, cần dễ dùng và đáng tin)
- Relaxation Seeker (đi để reset, cần chất lượng và premium)
- Family Traveler (đi cùng gia đình, cần an toàn và tiện lợi)
- Explorer (đi để trải nghiệm mới, budget-conscious, tần suất cao)

Giải thích segment nào phù hợp nhất và retention mechanic nào work với user này.
```

### Viết campaign message theo segment

```
Tôi đang chạy campaign travel nhắm đến [tên segment].

Motivation travel chính của họ: [mô tả]
Frustration lớn nhất của họ với booking platform: [mô tả]
Vertical đang promote: [airline / bus / train / hotel]
Mùa: [Tết / hè / 30/4 / cuối năm / thấp điểm]

Viết 3 variation message cho segment này:
1. Emotional angle (appeal to motivation)
2. Functional angle (address frustration)
3. Urgency angle (giá hoặc availability)

Format mỗi cái: headline (dưới 10 từ) + body (dưới 30 từ). Viết bằng tiếng Việt.
```

## 2. Campaign planning

### Build campaign brief

```
Tôi cần campaign brief cho một travel marketing campaign.

Context:
- Loại platform: [OTA / airline / bus / hotel]
- Vertical chính: [vertical]
- Mục tiêu campaign: [acquisition / retention / reactivation / brand]
- Target segment: [segment]
- Mùa / thời điểm: [cụ thể]
- Budget level: [lớn / trung bình / nhỏ — tương đối]
- Thời gian: [X tuần]

Build campaign brief bao gồm:
1. Objective (một câu, đo được)
2. Target audience (segment + behavioral profile)
3. Key message (một insight + một proof point)
4. Promotion mechanic đề xuất
5. Channel priority (xếp hạng)
6. 3 KPI với target cụ thể
7. Success trông như thế nào vs failure trông như thế nào
```

### Diagnose campaign underperform

```
Tôi vừa chạy một travel promotion campaign với kết quả sau:

Loại campaign: [ATL / BTL / partnership / gamification]
Target: [new user / current user / lapsed user]
Offer: [mô tả cụ thể — ví dụ "giảm 30% vé máy bay, tối đa 200k, hết hạn 7 ngày"]
Channel: [liệt kê các kênh đã dùng]
Reach: [X user]
Redemption rate: [X%]
Expected redemption rate: [X%]
Conversion to booking: [X%]

Campaign underperform. Diagnose nguyên nhân có khả năng nhất và đề xuất 3 thay đổi cụ thể cho lần tiếp theo.
```

## 3. Retention

### Design retention journey

```
Travel user vừa hoàn thành booking đầu tiên của họ.

Profile:
- Segment: [segment]
- Vertical vừa book: [vertical]
- Điểm đến: [thành phố]
- Ngày đi: [còn X ngày]
- Lịch sử platform: [user mới / đã có X booking trước]

Design retention journey 90 ngày:
- Ngày 1-3: gửi gì, kênh nào, message angle gì
- Ngày 14-30: content hoặc engagement nào
- Ngày 30-60: conversion push về booking 2 (offer type, mechanic, message)
- Ngày 60-90: reactivation nếu chưa có booking 2

Với mỗi touchpoint: kênh, message angle, offer nếu có, expected action.
```

### Identify retention risk

```
Tôi có một cohort travel user với đặc điểm sau:

- First booking: [X tháng trước]
- Số lần book kể từ đó: [X]
- Last booking: [X ngày trước]
- Vertical đã dùng: [liệt kê]
- Segment: [nếu biết]

Retention risk level của cohort này ở mức nào?
Top 3 signal nào predict churn trong travel user?
Retention mechanic nào bạn đề xuất và tại sao?
```

4. Tracking plan (đo incrementality như thế nào)
5. Success criteria để renew vs discontinue
```

Unique angle của tôi: [mình biết gì mà người khác không có]

Generate 10 content ideas:
- Match search intent với keywords mục tiêu
- Có thể viết không cần data nội bộ

Độ dài: [ngắn dưới 200 từ / trung bình 300-400 từ]

Viết bài không đề cập tên công ty hay data nội bộ.
Lead bằng insight, không phải backstory.
Kết bằng một câu hỏi hoặc một takeaway có thể action được ngay.
```

# 🤖 AI Prompts for Travel Growth Marketing

Prompts built specifically for travel growth work — not generic marketing prompts adapted for travel.

Each prompt is designed around real decisions travel marketers make: how to segment users, how to design campaigns, how to diagnose retention problems, how to brief partners.

## How to Use

Each prompt has a fill-in structure. Replace the brackets with your specific context. The more specific the input, the more useful the output.

These prompts work in Claude, ChatGPT, Gemini, or any capable AI assistant.

---

## 1. User Segmentation

### Classify a user into a travel segment

```
I have a travel platform user with the following behavior:

Booking history:
- Number of bookings: [X]
- Verticals used: [airline / bus / train / hotel — list all]
- Typical destination type: [beach / mountain / city / hometown]
- Travel party: [solo / couple / family / group]
- Booking lead time: [books X days/weeks in advance on average]
- Price range per trip: [budget / mid-range / premium]

Classify this user into one of 4 segments:
- Connection Seeker (travels to connect, values ease and reliability)
- Relaxation Seeker (travels to reset, values quality and premium experiences)
- Family Traveler (travels with family, values safety and convenience)
- Explorer (travels to experience new places, budget-conscious, higher frequency)

Explain which segment fits best and what retention mechanic would work for this user.
```

### Design segment-specific campaign messaging

```
I'm running a travel campaign targeting [segment name].

Their core travel motivation: [describe]
Their main frustration with booking platforms: [describe]
The vertical I'm promoting: [airline / bus / train / hotel]
The season: [Tết / summer / 30/4 / year-end / off-peak]

Write 3 message variations for this segment:
1. Emotional angle (appeal to motivation)
2. Functional angle (address frustration)
3. Urgency angle (price or availability)

Format each as: headline (under 10 words) + body copy (under 30 words).
```

---

## 2. Campaign Planning

### Build a campaign brief

```
I need a campaign brief for a travel marketing campaign.

Campaign context:
- Platform type: [OTA / airline / bus / hotel]
- Primary vertical: [vertical]
- Campaign goal: [acquisition / retention / reactivation / brand awareness]
- Target segment: [segment]
- Season / timing: [specific]
- Budget level: [large / medium / small — relative]
- Duration: [X weeks]

Build a campaign brief covering:
1. Objective (one sentence, measurable)
2. Target audience (segment + behavioral profile)
3. Key message (one insight + one proof point)
4. Promotion mechanic recommendation
5. Channel priority (ranked)
6. 3 KPIs with specific targets
7. What success looks like vs what failure looks like
```

### Diagnose a campaign that underperformed

```
I ran a travel promotion campaign with these results:

Campaign type: [ATL / BTL / partnership / gamification]
Target: [new users / current users / lapsed users]
Offer: [describe specifically — e.g. "30% discount on flights, max 200k VND, 7-day expiry"]
Channel: [list channels used]
Reach: [X users]
Redemption rate: [X%]
Expected redemption rate: [X%]
Conversion to booking: [X%]

The campaign underperformed. Diagnose the most likely reasons and suggest 3 specific changes for the next iteration.
```

## 3. Retention

### Design a retention journey

```
A travel user just completed their first booking.

Profile:
- Segment: [segment]
- Vertical just booked: [vertical]
- Destination: [city]
- Travel date: [X days from now]
- Platform history: [new user / returning user with X previous bookings]

Design a 90-day retention journey:
- Day 1-3: what to send, which channel, what message angle
- Day 14-30: what type of content or engagement
- Day 30-60: conversion push toward booking 2 (offer type, mechanic, message)
- Day 60-90: reactivation if no booking 2 yet

For each touchpoint: channel, message angle, offer if any, expected action.
```

### Identify retention risk

```
I have a cohort of travel users with these characteristics:

- First booking: [X months ago]
- Number of bookings since: [X]
- Last booking: [X days ago]
- Verticals used: [list]
- Segment: [if known]

What is the retention risk level for this cohort?
What are the top 3 signals that predict churn in a travel user?
What retention mechanic would you recommend and why?
```

## 4. Partner Co-marketing

### Brief a partnership campaign

```
I'm briefing a co-marketing campaign with [partner type].

Partner: [airline / bus operator / hotel chain / experience provider]
Campaign goal: [acquisition / brand awareness / volume for partner]
Offer type: [exclusive fare / bundle / loyalty points / co-branded voucher]
Duration: [X weeks]
Target audience: [segment]

Write a partner brief covering:
1. Campaign objective (for us and for the partner)
2. Offer mechanics (specific — e.g. "exclusive 15% discount on Route A for 7 days")
3. Asset requirements (what we need from them, what we provide)
4. Tracking plan (how we measure incrementality)
5. Success criteria for renewal vs discontinuation
```

## 5. Content and Inbound

### Generate travel content ideas

```
I'm building inbound content for a [vertical] platform targeting [segment].

Keywords I want to rank for: [list 3-5]
Content gap I've identified: [what competitors don't cover well]
Unique angle I have: [what I know that others don't]

Generate 10 content ideas that:
- Match search intent for my target keywords
- Can be written without proprietary data
- Have a clear CTA that drives platform usage
- Are differentiated from generic travel content

For each idea: title, target keyword, main angle, estimated word count.
```

### Write a travel growth insight post

```
I want to write a [Facebook post / LinkedIn post / X thread] about a growth marketing insight from the travel vertical.

The insight: [describe what you learned]
Audience: [growth marketers / OTA founders / travel tech teams]
Tone: [personal and direct / professional / educational]
Length: [short under 200 words / medium 300-400 words]

Write the post without mentioning specific company names or internal data.
Lead with the insight, not the backstory.
End with one question or one immediately actionable takeaway.
```
