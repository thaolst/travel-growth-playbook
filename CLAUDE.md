# Travel Growth Playbook

Frameworks and AI skills for travel growth marketing in Southeast Asia, particularly Vietnam. Covers airline, bus, train, and hotel verticals.

## Context

Travel growth is different from e-commerce or SaaS:
- Users book 2-4x/year — no natural habit loop
- Each booking is a deliberate, researched decision
- The same trip means different things to different people
- Cross-vertical (flight + hotel) is the biggest unlocked opportunity

This repo is structured as independent skills. Each folder contains a full framework plus ready-to-use prompts.

## Skills

| Command | Folder | What it does |
|---|---|---|
| `/segment` | `01-user-segmentation/` | Classify travel users by motivation (4 segments) |

## How to use a skill

```
/segment user profile: [describe bookings, verticals, destinations, travel party, timing]
```

Or open a skill file directly: `skills/<folder>/SKILL.md`

## Core frameworks referenced across skills

- **4 travel segments**: Connection Seeker, Relaxation Seeker, Family Traveler, Explorer
- **6-stage journey**: Inspire → Search → Consider → Book → Post-book → Post-trip
- **5 promotion types**: ATL, BTL, Partnership, Gamification, Loyalty
- **4 seasonal phases**: Tết peak, Post-Tết dip, Summer peak, Year-end build
- **60-90 day retention window**: Critical period between booking 1 and booking 2
- **Incrementality-first partnership**: Exclusive offer + measurable lift
